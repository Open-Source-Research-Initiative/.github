Open Source Research Initiative（OSRI）是一项由创始人牵头的倡议，正在寻找不同领域的协作者，共同研究问题。OSRI 希望通过由人主导的 Agentic-Powered-Research 汇集专业知识，并在 Git 中记录问题、证据、分析与发现，使协作者能够追踪并延续研究。

**Agentic-Powered-Research 由人主导：** 人来确定研究问题、指导工作，并评估证据与结论。

## 使命

汇集不同学科的参与者，共同主导 Agentic-Powered-Research，综合证据，通过开放、可追溯的研究寻找答案。

## 愿景

建立由人主导 Agentic-Powered-Research 的跨领域研究社区，连接已有知识。在共同研究记录的基础上，更快、更可靠地找到答案。

## 研究领域

OSRI 将从卫生健康、工程、信息学、经济学、社会与行为科学、公共政策开始，同时欢迎相关问题及其他学科的贡献。

- **卫生健康：** 公共卫生、卫生系统研究、证据综合与元分析，初期聚焦非临床研究。
- **工程：** 系统工程、工程管理、运筹学与决策科学，使用无须实体实验室实验的方法。
- **信息学：** 生物信息学、卫生与研究信息学、信息系统及计算自然科学，包括计算生物学、化学、物理学与材料建模。使用已有证据、数据与计算方法，无须实体实验室实验。
- **经济学：** 卫生经济学、公共经济学、激励、资源分配，以及研究与创新的经济学。
- **社会与行为科学：** 人的判断、协作、组织行为，以及人如何开展 Agentic-Powered-Research。
- **公共政策：** 政策分析与评估、治理、制度、技术政策和公共项目。

证据综合、元分析、建模与仿真可用于不同领域的研究。具体问题和项目将与协作者共同形成。

## OSRI 仿真实验室

拟议中的 **OSRI Simulation Lab** 将为各研究领域的虚拟实验提供支持，使用计算方法研究通常在实验室中考察的过程。由人指导工作、评估模型与证据，并判断结果能够支持哪些结论。

## 出版目标

OSRI 希望通过期刊论文、完整会议论文、arXiv 等平台的预印本，以及实质性的研究博客和技术文章分享成果。

按类型跟踪发表成果，并将相关成果关联到同一项研究工作。这样既能报告成果数量，也能报告独立研究工作的数量。同行评审状态单独记录。

## 元研究与管理

OSRI 管理员将研究并改进组织的研究实践，包括可复现性、证据质量、协作，以及 Agentic-Powered-Research 的使用。元研究属于整个组织的管理工作，涵盖各仓库与共同的仿真实验室。

这项工作包括评估 Agentic-Powered-Research 对研究质量、协作、时间与资源使用的影响。管理员还维护共同研究记录，并用所得改进 OSRI 的工作方式。

## 参与协作

OSRI 正在寻找具有领域知识、值得研究的问题，或研究工具与方法开发经验的协作者。欢迎一起形成首批项目，通过由人主导的 Agentic-Powered-Research 跨领域寻找答案。

在[问答区（Q&A）](https://github.com/Open-Source-Research-Initiative/.github/discussions/categories/q-a)提问或申请资源。在[想法区（Ideas）](https://github.com/Open-Source-Research-Initiative/.github/discussions/categories/ideas)提出研究主题。

在[成果分享区（Show and tell）](https://github.com/Open-Source-Research-Initiative/.github/discussions/categories/show-and-tell)分享发表成果、模型与有用的工作。
