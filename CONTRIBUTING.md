# Contribute to OSRI

Start with the [short research guide](https://github.com/Open-Source-Research-Initiative/osri/blob/main/START_HERE.md). It connects the question, evidence, method, review, writing, and publication steps.

Ask questions or request public resources in [Q&A](https://github.com/Open-Source-Research-Initiative/.github/discussions/new?category=q-a). Share research ideas in [Ideas](https://github.com/Open-Source-Research-Initiative/.github/discussions/new?category=ideas). Use the [project template](https://github.com/Open-Source-Research-Initiative/project-template) when ready.

Follow the [shared rules](https://github.com/Open-Source-Research-Initiative/osri/blob/main/governance/contribution-standards.md). Keep the task bounded, link evidence, report actual checks, and identify human review still needed. You may use your own agent or work manually.

Issues track agreed tasks; pull requests hold changes. A maintainer can help if Git is unfamiliar. A question or unchecked source lead needs no full form.

For confidential requests or concerns, contact [Cole](mailto:cole.lyons@pennmedicine.upenn.edu). Do not post credentials or restricted material publicly.
